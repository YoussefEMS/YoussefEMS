## Core strengths

- **AI and retrieval systems:** RAG pipelines, hybrid retrieval, embeddings, vector search, reranking, LLM-backed APIs, evaluation workflows.
- **Data engineering and BI:** star-schema data warehouses, ETL, OLAP cubes, SQL Server, SSIS, SSAS, MDX, Power BI.
- **Backend engineering:** FastAPI, REST APIs, authentication, PostgreSQL, SQL Server, SQLAlchemy, Pydantic, service-oriented project structure.
- **Big-data analytics:** PySpark pipelines, Redis-backed recommendation lookups, Docker Compose, behavior-event processing.
- **Data science:** statistical analysis, hypothesis testing, visualization, pandas, Plotly, SciPy, statsmodels.
- **Application development:** Flutter mobile apps, Streamlit apps, Scala backends, Python automation, testing, Git/GitHub workflows.
